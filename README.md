# GobyPOC

Goby 漏洞验证与利用（POC / Exp）集合，用于 Goby 客户端的自定义 POC 加载与日常**授权**安全测试。

> ⚠️ 本仓库内容仅限合法的授权测试与学习研究使用，禁止用于任何未授权的攻击行为。使用者自行承担全部责任。

## 目录结构

| 路径 | 内容 | 文件数 |
| --- | --- | --- |
| `system/` | Goby 官方 `.poc` 格式文件（二进制，无法查看 diff） | 107 |
| `user/` | 社区收集与自写 exp：`.go`（Goby 脚本引擎）+ `.json`（POC 定义 / 可视化配置） | 3481 |

## 规模

- POC / Exp 文件共 **3585** 个：`2405` 个 `.go`、`1073` 个 `.json`、`107` 个 `.poc`
- 其中 **1063** 个文件显式标注了 CVE 编号
- 覆盖面：Web 应用、OA/ERP（泛微、致远、通达、用友等）、中间件（Weblogic、Tomcat、Struts2、Spring、Shiro）、安全设备、网络设备、IoT 摄像头/路由器等
- 仓库体积约 **38 MB**（不含 `.git`）

## 使用方法

1. 关闭 Goby；
2. 把 `system/`、`user/` 复制到 Goby 安装目录下对应的同名目录（不同版本可能位于安装根目录或用户数据目录，以你本地实际结构为准）；
3. 重新启动 Goby，在 POC 管理中刷新，即可看到新增条目。

## 命名约定

- 文件名一般为 `厂商-产品-漏洞点-类型` 形式，并尽量带上 CVE / CNVD 编号，例如：
  `Weaver-e-cology-OA-RCE-(CNVD-2019-32204).json`
- `.go` 文件是 Goby 自定义脚本语法的 exp（`SetGet` / `SetPost` 等接口），**不是**可直接编译的标准 Go 代码；
- 部分条目存在 `(copy 1)` 之类的重复文件，属于收集过程中残留，不影响使用。
